## 4. Notes (no change needed)

- **n-1. J, recomputed:**
  - (2 + 0.8416)^2 / 0.01^2 = 80,749 units;
  - lower session bound 1042 - 48 = 994, so E_252 holds 743 complete starts;
  - 80,749 / 743 = 108.7, so J_needed = 109 and J_H4 = 128.

  The bound sd <= 1 holds because each per-unit composite difference lies in [-1, 1]. The start-keyed field makes
  units of different starts independent given the history, so the per-seed composite's variance is at most
  1 / n_252. With realistic per-unit sd (0.2-0.4) the J is conservative by a factor of 6 to 25. J reads no H4 output,
  and the sizing row may split parts by start range only. `three_way_seeds` 73-75 keeps a split part's id, so the
  keys and the pairing survive a split. Even with FOMC and early-close days also removed from the start calendar
  (about 962 sessions), J stays 128.
- **n-2. The one-uniform copy law is exact for nested losses with a common target.** With p_a = L_a / (L_a + g) and
  L_1 < L_2:
  - P(both win) = p_1;
  - P(account 2 wins | account 1 lost) = (p_2 - p_1) / (1 - p_1) = (L_2 - L_1) / (L_2 + g), the gambler's-ruin value
    from -L_1.
