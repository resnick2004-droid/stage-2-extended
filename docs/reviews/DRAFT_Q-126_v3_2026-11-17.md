**2. The closed-form bound, re-derived.**
- **The set-up.**
  - G(r) = P(Bin(N, r) <= c), which equals P(B > r) for B ~ Beta(c + 1, N - c). So -G'(r) is that beta density.
  - Eligibility is upward closed in m (bad counts are non-increasing in m on shared draws), so
    P(choice = m_i) = P_i - P_{i-1}.
  - Validation draws are independent of the calibration's, so
    P(choice = m_i and fails) = (P_i - P_{i-1})(1 - (1 - r_i)^n).
  - P_i <= G(r_i), so r_i <= G^-1(P_i), and the failure chance is at most h(P_i) = 1 - (1 - G^-1(P_i))^n.
- **The integral.** h decreases, so the sum is at most the integral of h over (0, 1). Substituting p = G(r), that is
  E[1 - (1 - R)^n] with R ~ Beta(c + 1, N - c). Since 1 - R ~ Beta(N - c, c + 1),
  E[(1 - R)^n] = prod_{i<n} (N - c + i)/(N + 1 + i).
- **At c = 0** the product telescopes to N/(N + n), so the bound is n/(N + n) = 115/3,415 = 0.03367.
- **Numerically**, at N = 3,300 and n = 115, the closed form, quadrature, the beta moment and a 20,000-step staircase
  agree to four places at c = 0..3: 0.03367, 0.06623, 0.09769, 0.12810. The one-candidate suprema are 0.01260, 0.02847,
  0.04597 and 0.06440.
- **At c = 0** the bound is exact under unequal rates across sizes too, since the validation's pass is the
  calibration's raised to 23/660.
