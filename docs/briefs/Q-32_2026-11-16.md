## The goal

1. **Blocks:** the choice block (2020-01-02 to 2023-12-29) and the judged block (2024-01-02 to 2026-07-16); anything

2. **Purpose tags:** a read declares `purpose` (e.g. `stage_A_supply`, `stage_C_judgement`, `identity`) and the
   declaration it serves (`prereg/F-xx_*.md`, checked to exist and to be **pinned** -- its sha256 in a decision row,
   as `tests/test_declarations_fixed.py` reads them). A read touching the judged block without a pinned declaration
   whose text names that purpose for the judged block **raises**; identities that must read Stage 2's whole window
   (E-004, E-010, E-011) carry the purpose `identity` and are allowed.
3. **The read ledger:** every judged-block read appends one line to `results/read_ledger.jsonl` (who -- script and
   commit; what -- files and columns; which dates; which declaration and purpose; when). Append-only; a hook or test
   makes a rewrite visible. (Add `read_ledger.jsonl` to the files `scripts/hooks/protect_results.py` allows, with a
   test.)
4. **Tests:** an untagged judged read raises; a choice-block read needs no tag; a tagged read under an unpinned or
   unnamed declaration raises; the ledger line is written and cannot be silently rewritten; 2026-07-17 is refused.
